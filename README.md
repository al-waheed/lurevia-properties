# LUREVIA Properties

A premium real-estate website built to showcase modern frontend development, responsive design, reusable React components, and thoughtful user experience.

## Overview

LUREVIA Properties is a fictional premium real-estate brand focused on residential properties, property discovery, agents, and client enquiries.

The project was designed to feel like a real production website rather than a template or demo.

## Features

- Responsive real-estate website
- Property listing and filtering
- Property detail pages
- Agent directory
- Individual agent profiles
- Contact form interaction
- Responsive mobile navigation
- Reusable React components
- Local structured property and agent data
- Dynamic routes with React Router
- Responsive layouts across desktop, tablet and mobile
- Hover and interaction states
- Production-ready Vite build

## Pages

- Home
- Properties
- Property Details
- Agents
- Agent Profile
- About
- Contact

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React
